# Organizational Psychology Code

Open computational scaffolding for the Organizational Psychology knowledge series.

This repository supports article-level examples for leadership, authority, motivation, incentives, goal systems, job satisfaction, organizational commitment, team dynamics, trust, cooperation, conflict, psychological safety, organizational culture, institutional values, organizational identity, legitimacy, decision-making, cognitive bias, information flow, organizational communication, strategic decision-making, organizational change, resistance, learning organizations, and organizational resilience.

## Structure

Each article folder contains:

- `python/`
- `r/`
- `julia/`
- `cpp/`
- `fortran/`
- `c/`
- `rust/`
- `go/`
- `sql/`
- `notebooks/`
- `docs/`
- `data/raw/`
- `data/processed/`
- `outputs/`
