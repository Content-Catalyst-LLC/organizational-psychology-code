# Cognitive Bias in Institutional Decisions

This companion scaffold supports the article **“Cognitive Bias in Institutional Decisions.”** It provides synthetic datasets, reproducible workflows, documentation, validation notes, and multi-language examples for studying cognitive bias as an institutional decision-system condition rather than an individual defect.

The scaffold treats bias pressure as a system-level property shaped by signal quality, viewpoint diversity, analytical discipline, structured challenge, hierarchy suppression, time pressure, routine reinforcement, learning review, group conformity, and decision error risk.

## Research purpose

This repository is designed for:

- organizational psychology methods demonstration
- synthetic-data modeling
- institutional decision-governance review
- bias-risk analysis
- strategic decision-quality diagnostics
- learning-review and postmortem workflow education
- responsible and reproducible organizational analytics
- teaching examples for decision systems, bounded rationality, and institutional learning

It is not designed for employee scoring, workplace surveillance, psychological assessment, executive ranking, hiring, promotion, discipline, termination, or compensation decisions.

## Conceptual frame

The synthetic workflow models cognitive bias pressure as a system-level construct shaped by:

- signal quality
- viewpoint diversity
- analytical discipline
- structured challenge
- hierarchy suppression
- time pressure
- routine reinforcement
- learning review intensity
- group conformity
- decision error risk
- review priority

## Responsible-use notice

These materials are for synthetic-data research, methods demonstration, institutional learning, decision-governance review, bias-risk analysis, and reproducible workflows.

They are **not** employee-screening tools, employment-selection tools, hiring tools, promotion tools, compensation tools, discipline tools, termination tools, workplace surveillance systems, individual performance-management systems, psychological assessment tools, productivity-ranking tools, or executive-ranking systems.

The appropriate unit of analysis is the organization, decision process, governance structure, strategic review system, project review system, or institutional condition—not the worth, intelligence, loyalty, employability, competence, adaptability, objectivity, or psychological status of any individual worker or leader.

## Suggested workflow

1. Read `docs/ethics-scope-note.md`.
2. Review `docs/research-design.md`.
3. Inspect `docs/data-dictionary.md`.
4. Run the Python workflow in `python/bias_pressure_decision_model.py`.

6. Use `sql/schema.sql` for a reproducible relational representation.
7. Review `docs/validation-plan.md` and `docs/model-card.md`.
