# Method Notes

This scaffold demonstrates how cognitive bias pressure can be modeled while preserving interpretive caution.

## Conceptual model

The model treats bias pressure as an interaction among:

- signal quality
- viewpoint diversity
- analytical discipline
- structured challenge
- hierarchy suppression
- time pressure
- routine reinforcement
- learning review
- group conformity

## Suggested methods

- descriptive diagnostics
- unit-level bias-risk dashboards
- logistic regression for decision error
- escalation-of-commitment review
- bias-risk scoring
- scenario analysis
- sensitivity analysis
- qualitative validation
- decision-governance review

## Methodological caution

Bias pressure is partly measurable but not fully captured by metrics. It involves meaning, power, history, incentives, culture, authority, uncertainty, communication, and lived experience. Quantitative outputs should be paired with qualitative research and ethical governance.
