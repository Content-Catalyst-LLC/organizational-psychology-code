# Model Card: Synthetic Bias Pressure and Decision Error Workflow

## Model name

Synthetic Bias Pressure, Bias Risk, and Decision Error Workflow

## Intended use

This workflow is intended for synthetic-data demonstration, research-methods teaching, institutional learning, decision-governance review, bias-risk analysis, and reproducible organizational psychology examples.

## Not intended for

- employee screening
- employee ranking
- executive ranking
- employment selection
- hiring
- promotion
- compensation
- discipline
- termination
- workplace surveillance
- individual performance management
- productivity ranking
- psychological assessment

## Data

The included dataset is synthetic. It does not describe real employees, real executives, real teams, or real organizations.

## Outputs

The workflow can produce:

- bias pressure scores
- bias risk scores
- decision error predictions
- escalation-of-commitment summaries
- review priority categories
- scenario comparisons

## Interpretation

Outputs should be interpreted as institutional inquiry prompts, not automated decisions. Any real-world use would require domain expertise, qualitative validation, ethics review, stakeholder consultation, and governance oversight.

## Known limitations

- Synthetic data cannot validate real-world causal claims.
- Variables simplify complex organizational phenomena.
- Quantitative scores may obscure power, culture, status, history, and context.
- Cognitive bias cannot be fully represented through metrics.
- Model outputs may be misused without strong governance.
