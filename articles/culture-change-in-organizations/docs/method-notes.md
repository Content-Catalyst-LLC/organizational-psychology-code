# Method Notes

This scaffold demonstrates how culture change capacity can be modeled while preserving interpretive caution.

## Conceptual model

The model treats culture change capacity as an interaction among:

- leadership credibility
- narrative coherence
- reinforcement alignment
- adaptive learning
- psychological safety
- identity adaptability
- resistance intensity
- subcultural fragmentation
- legacy lock-in
- leadership turnover

## Suggested methods

- descriptive diagnostics
- unit-level culture-change dashboards
- logistic regression for successful cultural adoption
- symbolic culture-change risk review
- culture risk scoring
- scenario analysis
- sensitivity analysis
- qualitative validation
- governance review

## Methodological caution

Culture is partly measurable but not fully captured by metrics. It involves meaning, memory, power, trust, identity, ritual, professional pride, legitimacy, and lived experience. Quantitative outputs should be paired with qualitative research, participatory interpretation, and ethical governance.
