# Decision-Making in Organizations

Professional companion-code scaffold for the Organizational Psychology article `decision-making-organizations`.

This folder supports reproducible research workflows for organizational decision-making under uncertainty: information quality, psychological safety, incentive alignment, interpretive diversity, coordination load, time pressure, bias pressure, leadership fragmentation, metric distortion, implementation error, decision review, institutional learning, and responsible interpretation.

## Scope

These examples use synthetic data. They are intended for organizational psychology research, decision science, institutional learning, leadership research, people analytics methods, governance review, and graduate teaching.

They are not employee-screening, hiring, promotion, compensation, disciplinary, workplace surveillance, individual performance-management, psychological assessment, or employment-selection tools.

## Structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level decision-quality scoring example in C. |
| `cpp/` | Typed decision-quality scoring in C++. |
| `data/` | Synthetic decision panel and context audit data. |
| `docs/` | Data dictionary, method notes, validation plan, ethics/scope, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical scoring example. |
| `go/` | Go command-line scoring example. |
| `julia/` | Decision-system dynamics simulation. |
| `notebooks/` | Notebook placeholders for exploratory workflows. |
| `outputs/` | Generated figures, tables, diagnostics, and reports. |
| `python/` | Decision analytics, risk scoring, and implementation-error modeling. |
| `r/` | Decision-quality, risk, and implementation-error modeling workflow. |
| `rust/` | Safe explicit scoring example in Rust. |
| `sql/` | Relational schema and analytical views. |
