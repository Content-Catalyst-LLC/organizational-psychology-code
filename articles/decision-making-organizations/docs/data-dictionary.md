# Data Dictionary

| Variable | Direction | Description |
|---|---|---|
| `information_quality` | Higher is better | Relevance, freshness, completeness, and decision-fit of evidence. |
| `psychological_safety` | Higher is better | Whether dissent, uncertainty, and error reporting are protected. |
| `incentive_alignment` | Higher is better | Whether rewards support truth, learning, and long-term purpose. |
| `interpretive_diversity` | Higher is better | Breadth of perspectives included in framing and challenge. |
| `coordination_load` | Higher is more costly | Communication and handoff burden across people or functions. |
| `time_pressure` | Higher is more pressure | Urgency and time constraint. |
| `bias_pressure` | Higher is worse | Vulnerability to confirmation bias, anchoring, escalation, groupthink, or status-quo bias. |
| `leadership_fragmentation` | Higher is worse | Conflicting direction or unclear ownership. |
| `metric_distortion` | Higher is worse | Proxy blindness, gaming, stale indicators, or detached measures. |
| `decision_quality_score` | Higher is better | Synthetic composite representing process and expected effectiveness. |
| `implementation_error_rate` | Lower is better | Synthetic downstream implementation failure rate. |
| `major_error_event` | Lower is better | Synthetic indicator of significant implementation failure. |
| `learning_capacity` | Higher is better | Ability to review, interpret, and revise after consequences emerge. |
