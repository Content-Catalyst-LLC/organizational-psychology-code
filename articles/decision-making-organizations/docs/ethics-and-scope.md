# Ethics and Scope

This repository supports non-punitive organizational learning.

It should not be used as:

- an employee-screening system;
- a hiring or promotion system;
- a disciplinary tool;
- a workplace surveillance system;
- an individual performance score;
- a tool for identifying or punishing dissenters;
- a substitute for leadership accountability.

Any real-world use requires validated measures, privacy safeguards, labor and employment-law review, fairness review, worker voice protections, anti-retaliation safeguards, and separation between learning analytics and performance management.
