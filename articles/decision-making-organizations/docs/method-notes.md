# Method Notes

A transparent decision-quality index can be written as:

```text
decision_quality =
  information_quality
+ psychological_safety
+ incentive_alignment
+ interpretive_diversity
+ learning_capacity
- coordination_load
- time_pressure
- bias_pressure
- leadership_fragmentation
- metric_distortion
```

A transparent institutional-risk index can be written as:

```text
institutional_decision_risk =
  low_information_quality
+ low_psychological_safety
+ low_incentive_alignment
+ high_coordination_load
+ high_time_pressure
+ high_bias_pressure
+ high_leadership_fragmentation
+ high_metric_distortion
+ implementation_error_rate
```

Use these examples for research scaffolding and methods demonstration only.
