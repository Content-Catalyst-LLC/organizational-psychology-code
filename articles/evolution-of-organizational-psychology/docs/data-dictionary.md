# Data Dictionary

## `data/raw/organizational_psychology_evolution_synthetic.csv`

This synthetic dataset represents historical periods and field-emphasis scores. It is designed for methods demonstration only.

| Field | Description | Scale |
|---|---|---|
| `period` | Historical period label | Categorical |
| `selection_testing` | Emphasis on selection, testing, psychometrics, assessment, and person-job fit | 0–100 |
| `efficiency_work_design` | Emphasis on efficiency, task design, workflow, job design, and performance systems | 0–100 |
| `motivation_attitudes` | Emphasis on motivation, job attitudes, engagement, satisfaction, and commitment | 0–100 |
| `groups_teams` | Emphasis on group dynamics, teams, communication, trust, and coordination | 0–100 |
| `culture_leadership_change` | Emphasis on culture, leadership, organizational development, and change | 0–100 |
| `wellbeing_stress` | Emphasis on occupational stress, burnout, recovery, work design, and well-being | 0–100 |
| `justice_validity_ethics` | Emphasis on fairness, validity, law, ethics, accountability, and responsible use | 0–100 |
| `digital_analytics` | Emphasis on digital work, people analytics, algorithmic management, AI, and data governance | 0–100 |
| `systems_institutional_accountability` | Emphasis on systems thinking, institutions, power, governance, and accountability | 0–100 |

## Interpretation

The dataset is synthetic. It does not report actual publication counts, citation data, society membership records, archival evidence, occupational data, or expert-coded history. It is a conceptual teaching artifact.
