# Model Card: Synthetic Information Flow Quality Workflow

## Model name

Synthetic Information Flow Quality, Communication Risk, and Decision Error Workflow

## Intended use

This workflow is intended for synthetic-data demonstration, research-methods teaching, institutional learning, organizational communication review, knowledge-flow governance, decision-process review, and reproducible organizational psychology examples.

## Not intended for

- employee screening
- employee ranking
- employment selection
- hiring
- promotion
- compensation
- discipline
- termination
- workplace surveillance
- individual performance management
- communication surveillance
- message monitoring
- productivity ranking
- psychological assessment

## Data

The included dataset is synthetic. It does not describe real employees, real executives, real teams, or real organizations.

## Outputs

The workflow can produce:

- information flow quality scores
- communication risk scores
- decision error predictions
- escalation failure summaries
- review priority categories
- scenario comparisons

## Interpretation

Outputs should be interpreted as institutional inquiry prompts, not automated decisions. Any real-world use would require domain expertise, qualitative validation, ethics review, worker consultation, privacy review, and governance oversight.

## Known limitations

- Synthetic data cannot validate real-world causal claims.
- Variables simplify complex organizational phenomena.
- Quantitative scores may obscure power, culture, status, trust, history, and context.
- Information flow cannot be fully represented through metrics.
- Model outputs may be misused without strong governance.
