# Institutional Values and Behavioral Expectations

This companion scaffold supports the article **“Institutional Values and Behavioral Expectations.”** It provides synthetic datasets, reproducible workflows, documentation, validation notes, and multi-language examples for studying institutional values as system-level conditions that shape behavioral expectations, value-practice alignment, legitimacy, psychological safety, accountability, and organizational learning.

The scaffold treats institutional values not as slogans, brand language, individual loyalty, or cultural-fit markers, but as organizational governance conditions shaped by value clarity, leadership consistency, reinforcement alignment, psychological safety, accountability strength, decoupling risk, incentive contradiction, hierarchy exemption, legitimacy pressure, stakeholder trust, and values credibility.

## Research purpose

This repository is designed for:

- organizational psychology methods demonstration
- synthetic-data modeling
- values-governance diagnostics
- institutional ethics research scaffolding
- legitimacy and trust analysis
- behavioral-expectation review
- value-practice alignment analysis
- decoupling and symbolic-values risk review
- institutional learning and accountability review
- responsible and reproducible organizational analytics

It is not designed for employee scoring, morality scoring, cultural-loyalty scoring, workplace surveillance, psychological assessment, productivity ranking, employment decision-making, or individual values-alignment labeling.

## Conceptual frame

The synthetic workflow models institutional values credibility and value-practice alignment as system-level constructs shaped by:

- value clarity
- leadership consistency
- reinforcement alignment
- psychological safety
- accountability strength
- decoupling risk
- incentive contradiction
- hierarchy exemption
- legitimacy pressure
- values credibility
- stakeholder trust
- symbolic values risk
- behavioral expectation internalization

## Responsible-use notice

These materials are for synthetic-data research, methods demonstration, institutional learning, values-governance review, organizational ethics education, legitimacy analysis, and reproducible workflows.

They are **not** employee-screening tools, employment-selection tools, hiring tools, promotion tools, compensation tools, discipline tools, termination tools, workplace surveillance systems, individual performance-management systems, cultural-loyalty scoring tools, cultural-fit tools, morality scoring tools, productivity-ranking tools, psychological assessment tools, or values-alignment scoring tools for workers or leaders.

The appropriate unit of analysis is the organization, values system, governance structure, institutional field, stakeholder relationship, organizational unit, cultural system, or legitimacy condition—not the worth, loyalty, morality, values alignment, identity, attitude, cultural fit, employability, psychological status, or ethical status of any individual worker.

## Suggested workflow

1. Read `docs/ethics-scope-note.md`.
2. Review `docs/research-design.md`.
3. Inspect `docs/data-dictionary.md`.
4. Run the Python workflow in `python/institutional_values_model.py`.
5. Run the R workflow in `r/institutional_values_model.R`.
6. Use `sql/schema.sql` for a reproducible relational representation.
7. Review `docs/validation-plan.md`, `docs/model-card.md`, and `docs/governance-checklist.md`.
8. Use the WordPress GitHub embed block in `github-embed-wordpress.html`.
