# Data Dictionary

## `data/raw/institutional_values_synthetic.csv`

This synthetic dataset describes organizational units across repeated institutional-values review periods. It is designed for methods demonstration only.

| Field | Description | Scale |
|---|---|---|
| `unit_id` | Synthetic organizational unit identifier | Categorical |
| `period` | Synthetic observation period | Integer |
| `value_clarity` | Clarity of declared values and role-specific behavioral expectations | 0–100 |
| `leadership_consistency` | Consistency between leadership value language, behavior, decisions, and resource allocation | 0–100 |
| `reinforcement_alignment` | Alignment among incentives, recognition, promotion, sanctions, and stated institutional values | 0–100 |
| `psychological_safety` | Ability to name contradictions, raise concerns, and challenge value-practice gaps safely | 0–100 |
| `accountability_strength` | Strength and fairness of accountability across hierarchy levels | 0–100 |
| `decoupling_risk` | Risk that formal values are separated from actual institutional behavior | 0–100 |
| `incentive_contradiction` | Degree to which incentives reward behavior that conflicts with stated values | 0–100 |
| `hierarchy_exemption` | Degree to which high-status actors appear exempt from values enforcement | 0–100 |
| `legitimacy_pressure` | External pressure from stakeholders, regulators, publics, fields, or communities | 0–100 |
| `values_credible` | Synthetic binary indicator of whether values are experienced as credible | 0/1 |
| `symbolic_values_risk` | Synthetic binary indicator of values language without deeper institutional alignment | 0/1 |

## Interpretation

Variables are institutional, unit-level, values-system, and governance-system indicators. They should not be interpreted as measures of individual morality, values alignment, loyalty, cultural fit, performance, personality, legitimacy, or psychological status.
