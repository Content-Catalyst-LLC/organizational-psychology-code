# Method Notes

This scaffold demonstrates how institutional values credibility and value-practice alignment can be modeled while preserving interpretive caution.

## Conceptual model

The model treats value-practice alignment as an interaction among:

- value clarity
- leadership consistency
- reinforcement alignment
- psychological safety
- accountability strength
- decoupling risk
- incentive contradiction
- hierarchy exemption
- legitimacy pressure

## Suggested methods

- descriptive diagnostics
- unit-level values-governance review dashboards
- logistic regression for values credibility
- symbolic values-risk review
- value-practice alignment scoring
- scenario analysis
- sensitivity analysis
- qualitative validation
- ethics and governance review
- stakeholder legitimacy review

## Methodological caution

Institutional values and behavioral expectations are partly measurable but not fully captured by metrics. They involve meaning, power, trust, hierarchy, ethical obligation, lived experience, institutional memory, field-level legitimacy, and material conditions. Quantitative outputs should be paired with qualitative research and ethical governance.
