# Model Card: Synthetic Institutional Values and Behavioral Expectations Workflow

## Model name

Synthetic Value-Practice Alignment, Values Credibility, and Symbolic Values Risk Workflow

## Intended use

This workflow is intended for synthetic-data demonstration, research-methods teaching, institutional learning, values-governance review, organizational ethics education, legitimacy analysis, and reproducible organizational psychology examples.

## Not intended for

- employee screening
- employee ranking
- cultural-loyalty scoring
- cultural-fit scoring
- morality scoring
- values-alignment scoring of workers
- employment selection
- hiring
- promotion
- compensation
- discipline
- termination
- workplace surveillance
- individual performance management
- productivity ranking
- psychological assessment

## Data

The included dataset is synthetic. It does not describe real employees, real executives, real teams, real stakeholders, or real organizations.

## Outputs

The workflow can produce:

- value-practice alignment scores
- institutional values risk scores
- values credibility predictions
- symbolic values-risk summaries
- review priority categories
- scenario comparisons

## Interpretation

Outputs should be interpreted as institutional inquiry prompts, not automated decisions. Any real-world use would require domain expertise, qualitative validation, ethics review, worker and stakeholder consultation, privacy review, and governance oversight.

## Known limitations

- Synthetic data cannot validate real-world causal claims.
- Variables simplify complex values, ethics, and legitimacy phenomena.
- Quantitative scores may obscure power, hierarchy, trust, workload, memory, field conditions, and lived experience.
- Institutional values cannot be fully represented through metrics.
- Model outputs may be misused without strong governance.
