# Table CSS Note

For WordPress article tables, use the current site-compatible pattern:

```html
<div class="cc-table-wrap">
<table class="cc-table">
<thead>
<tr>
<th>Column</th>
<th>Column</th>
</tr>
</thead>
<tbody>
<tr>
<td>Value</td>
<td>Value</td>
</tr>
</tbody>
</table>
</div>
```

Do not use `cc-custom-table`. The current table class is `cc-table`.
