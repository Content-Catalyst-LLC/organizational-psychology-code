# Validation Plan

This validation plan applies to synthetic methods demonstration. It does not validate a real-world employment, personnel, or psychological assessment tool.

## 1. Construct validation

Review whether variables represent change-system conditions rather than individual worker traits.

Key questions:

- Does the measure describe the change process?
- Does it describe implementation conditions?
- Does it describe governance, legitimacy, learning, or resource capacity?
- Could it be misused to label individuals?

## 2. Data quality review

In real-world research, examine:

- source provenance
- missing data
- survey-response bias
- underreporting of dissent
- fear of retaliation
- uneven participation
- changes in measurement over time
- context behind numeric indicators

## 3. Model validation

Assess:

- coefficient stability
- sensitivity to weighting choices
- uncertainty
- outlier influence
- subgroup interpretability
- qualitative plausibility
- whether model outputs match lived organizational experience

## 4. Ethical validation

Confirm that the workflow cannot reasonably be repurposed for individual worker monitoring, ranking, punishment, or employment decisions.

## 5. Action validation

A change-governance review is only useful if it leads to responsible institutional improvement. Track whether findings lead to:

- clearer governance
- better participation
- improved resourcing
- trust repair
- workload relief
- revised sequencing
- better knowledge systems
- reduced symbolic change
