# Data Dictionary

## `data/raw/organizational_culture_synthetic.csv`

This synthetic dataset describes organizational units across repeated cultural review periods. It is designed for methods demonstration only.

| Field | Description | Scale |
|---|---|---|
| `unit_id` | Synthetic organizational unit identifier | Categorical |
| `period` | Synthetic observation period | Integer |
| `value_alignment` | Alignment between espoused values and lived institutional practice | 0–100 |
| `normative_consistency` | Consistency of informal norms across situations and units | 0–100 |
| `leadership_credibility` | Consistency between leadership messages, behavior, accountability, and resource allocation | 0–100 |
| `psychological_safety` | Ability to speak, report, question, and challenge without disproportionate penalty | 0–100 |
| `shared_meaning` | Clarity of shared interpretation around purpose, authority, risk, and responsibility | 0–100 |
| `contradiction` | Visible contradiction between official culture and lived behavior | 0–100 |
| `fragmentation` | Degree of subcultural fragmentation across units, professions, hierarchy, or geography | 0–100 |
| `incentive_distortion` | Degree to which incentives reward behavior inconsistent with declared culture | 0–100 |
| `external_pressure` | Pressure from stakeholders, regulators, markets, professions, communities, or public expectations | 0–100 |
| `strong_institutional_performance` | Synthetic binary indicator of performance integrity | 0/1 |
| `symbolic_culture_risk` | Synthetic binary indicator of culture language without deeper institutional alignment | 0/1 |

## Interpretation

Variables are institutional, unit-level, cultural-system, and governance-system indicators. They should not be interpreted as measures of individual loyalty, cultural fit, attitude, performance, personality, morality, or psychological status.
