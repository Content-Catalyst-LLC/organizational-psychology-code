# Organizational Resilience in Complex Systems

This companion scaffold supports the article **“Organizational Resilience in Complex Systems.”** It provides synthetic datasets, reproducible workflows, and multi-language examples for exploring organizational resilience as an institutional capacity shaped by robustness, redundancy, adaptive learning, psychological safety, coordination integrity, governance responsiveness, external exposure, complexity load, and accumulated fragility.

The scaffold is designed for organizational psychology research methods, institutional learning, systems thinking, and reproducible demonstration. It is intentionally synthetic and should be adapted only with careful ethical review, domain expertise, and appropriate governance.

## Research focus

This scaffold models resilience as a system-level construct rather than as an individual trait. The synthetic variables include:

- baseline robustness
- redundancy and backup capacity
- adaptive learning
- coordination integrity
- governance responsiveness
- psychological safety and signal transparency
- external exposure
- complexity load
- accumulated internal fragility
- shock intensity
- recovery and functional degradation outcomes

## Responsible-use notice

These materials are for synthetic-data research, methods demonstration, institutional learning, and reproducible workflows.

They are **not** employee-screening tools, employment-selection tools, hiring tools, promotion tools, compensation tools, discipline tools, termination tools, workplace surveillance systems, individual performance-management systems, or psychological assessment tools.

The appropriate unit of analysis is the institution, work system, team process, or organizational condition—not the worth, personality, resilience, or employability of an individual worker.

## Suggested use

1. Review `docs/ethics-scope-note.md`.
2. Inspect `data/raw/organizational_resilience_synthetic.csv`.
3. Run the Python workflow in `python/resilience_model.py`.
4. Run the R workflow in `r/resilience_model.R`.
5. Use the SQL schema in `sql/schema.sql` for reproducible data loading.
6. Review the validation and interpretation guidance in `docs/validation-plan.md`.

## Outputs

The workflows write demonstration outputs to:

- `outputs/tables/`
- `outputs/figures/`

The generated outputs are illustrative and should not be interpreted as findings about any real organization.
