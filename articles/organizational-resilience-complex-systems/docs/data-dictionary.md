# Data Dictionary

## `data/raw/organizational_resilience_synthetic.csv`

This synthetic dataset describes organizational units across repeated periods. It is designed for methods demonstration only.

| Field | Description | Scale |
|---|---|---|
| `unit_id` | Synthetic organizational unit identifier | Categorical |
| `period` | Synthetic observation period | Integer |
| `robustness` | Ability to maintain core function under disturbance | 0–100 |
| `redundancy` | Backup capacity, substitute pathways, or reserve knowledge | 0–100 |
| `adaptive_learning` | Ability to learn from disruption and revise routines | 0–100 |
| `coordination_integrity` | Ability to coordinate across units under strain | 0–100 |
| `governance_responsiveness` | Responsiveness of formal authority, oversight, and decision systems | 0–100 |
| `psychological_safety` | Ability for concern, error, dissent, and weak signals to surface | 0–100 |
| `external_exposure` | Exposure to environmental, market, regulatory, technological, or supply disruption | 0–100 |
| `complexity_load` | System complexity and coordination burden | 0–100 |
| `accumulated_fragility` | Latent brittleness produced by overload, unresolved errors, and hidden dependence | 0–100 |
| `shock_intensity` | Synthetic disruption intensity | 0–100 |
| `successful_recovery` | Synthetic binary recovery outcome | 0/1 |
| `major_functional_degradation` | Synthetic binary degradation outcome | 0/1 |

## Interpretation

Variables are institutional and system-level indicators. They should not be interpreted as measures of individual employee resilience, personality, commitment, or performance.
