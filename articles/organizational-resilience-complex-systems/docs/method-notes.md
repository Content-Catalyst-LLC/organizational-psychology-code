# Method Notes

This scaffold demonstrates how organizational resilience can be translated into a reproducible research workflow while preserving interpretive caution.

## Conceptual model

The model treats resilience capacity as an interaction among:

- robustness
- redundancy
- adaptive learning
- coordination integrity
- governance responsiveness
- psychological safety
- external exposure
- complexity load
- accumulated fragility

The conceptual aim is to help researchers reason about resilience as an emergent institutional capacity.

## Appropriate methods

Useful approaches may include:

- descriptive dashboards for unit-level review
- mixed-effects models for repeated organizational observations
- logistic regression for synthetic recovery outcomes
- scenario analysis
- sensitivity analysis
- qualitative validation through interviews, after-action reviews, and document analysis

## Limits

The data are synthetic. Results are illustrative. Any real-world application requires:

- institutional review
- ethical governance
- consultation with affected workers and stakeholders
- privacy protections
- anti-surveillance safeguards
- qualitative interpretation
- careful attention to power, incentives, and unintended consequences
