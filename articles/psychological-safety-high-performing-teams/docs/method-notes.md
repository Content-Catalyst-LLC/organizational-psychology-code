# Method Notes

This scaffold demonstrates how psychological safety, voice behavior, and team performance can be modeled while preserving interpretive caution.

## Conceptual model

The model treats psychological safety as an interaction among:

- leadership openness
- inclusion quality
- learning review quality
- knowledge sharing
- blame intensity
- status asymmetry
- perceived penalty
- workload pressure

## Suggested methods

- descriptive diagnostics
- team-level safety dashboards
- logistic regression for strong team performance
- symbolic voice-risk review
- safety-risk scoring
- scenario analysis
- sensitivity analysis
- qualitative validation
- meeting process review
- leadership response review

## Methodological caution

Psychological safety is partly measurable but not fully captured by metrics. It involves meaning, status, trust, fear, leadership response, prior experience, power, team history, and institutional memory. Quantitative outputs should be paired with qualitative research and ethical governance.
