# Method Notes

This scaffold demonstrates how resistance to organizational change can be modeled while preserving interpretive caution.

## Conceptual model

The model treats resistance intensity as an interaction among:

- perceived loss
- uncertainty
- identity threat
- routine embeddedness
- power displacement
- workload strain
- trust in leadership
- participation quality
- implementation clarity
- failed change history

## Suggested methods

- descriptive diagnostics
- unit-level dashboards
- logistic regression for constructive adoption
- symbolic compliance risk review
- change-friction scoring
- sensitivity analysis
- scenario analysis
- qualitative validation
- governance review

## Methodological caution

Resistance is partly measurable but not fully captured by metrics. It involves meaning, history, power, trust, culture, and lived experience. Quantitative outputs should be paired with qualitative research and ethical governance.
