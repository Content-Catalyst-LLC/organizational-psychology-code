# Method Notes

This scaffold demonstrates how transformational capacity, adaptive performance risk, voice-suppression risk, and purpose-exploitation risk can be modeled while preserving interpretive caution.

## Conceptual model

The model treats transformational capacity as an interaction among:

- vision credibility
- motivational alignment
- intellectual stimulation
- developmental support
- institutional trust
- psychological safety
- change communication
- implementation support
- meaning-making quality
- resistance intensity
- ambiguity pressure
- change fatigue

## Suggested methods

- descriptive diagnostics
- unit-level transformational-leadership dashboards
- logistic regression for adaptive performance risk
- change-fatigue and ambiguity review
- voice-suppression risk review
- purpose-exploitation risk review
- scenario analysis
- sensitivity analysis
- qualitative validation
- change-readiness review
- communication audit
- leadership feedback review
- workload and staffing review
- psychological safety assessment
- implementation support review

## Methodological caution

Transformational leadership is partly measurable but not fully captured by metrics. It involves vision, meaning, identity, trust, power, culture, voice, expertise, development, workload, fear, fatigue, ethics, and lived experience. Quantitative outputs should be paired with qualitative research and ethical governance.
