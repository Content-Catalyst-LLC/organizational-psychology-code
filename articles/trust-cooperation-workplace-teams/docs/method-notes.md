# Method Notes

This scaffold demonstrates how cooperative capacity, trust risk, and strong collaboration can be modeled while preserving interpretive caution.

## Conceptual model

The model treats cooperative capacity as an interaction among:

- competence trust
- integrity trust
- benevolence trust
- reciprocity norms
- communication reliability
- leadership credibility
- institutional trust
- opportunism risk
- power imbalance
- uncertainty load

## Suggested methods

- descriptive diagnostics
- team-level trust dashboards
- logistic regression for strong collaboration
- symbolic cooperation-risk review
- trust-risk scoring
- scenario analysis
- sensitivity analysis
- qualitative validation
- decision follow-through review
- reciprocity and workload review
- cross-functional trust review

## Methodological caution

Trust and cooperation are partly measurable but not fully captured by metrics. They involve meaning, history, power, fairness, vulnerability, institutional memory, workload distribution, credibility, leadership behavior, and lived experience. Quantitative outputs should be paired with qualitative research and ethical governance.
